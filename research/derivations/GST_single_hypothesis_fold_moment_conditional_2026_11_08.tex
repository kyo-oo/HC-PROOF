\section{Exact conditional cycle construction}
\begin{theorem}
If the above native fold-Hankel package exists for every original X and every live p, the rational Hodge conjecture holds for all such X.
\end{theorem}
\begin{proof}
For each j let \(Z_j=N^jZ_0\) and \(v_j=T^jv_0\).
Naturality inductively proves \(\cl_X(Z_j)=v_j\).
Define rational linear maps
\[
 C:\Q^n\to W,\quad C(e_j)=v_j,\qquad
 O:W\to\Q^n,\quad (O\beta)_i=\ell(T^i\beta).
\]
By construction \(M=OC\). Since \(\det M\neq0\) and
both the domain and codomain of C and O have dimension n,
C and O are isomorphisms. For ANY prescribed class alpha,
form the target-only moment vector and its coefficients:
\[
 b_i(\alpha)=\ell(T^i\alpha),\qquad c(\alpha)=M^{-1}b(\alpha).
\]
The EXPLICIT original-X native cycle is
\[
 \boxed{Z_\alpha=\sum_{j=0}^{n-1}c_j(\alpha)N^j Z_0.}
\]
All coefficients are rational and all summands are actual algebraic
cycles. Apply O to the class:
\[
 O\cl_X(Z_\alpha)=OCM^{-1}b(\alpha)
 =MM^{-1}O\alpha=O\alpha.
\]
Injectivity of O proves \(\cl_X(Z_\alpha)=\alpha\).
\end{proof}
