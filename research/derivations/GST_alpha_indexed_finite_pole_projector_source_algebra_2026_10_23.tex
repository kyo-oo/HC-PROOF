\begin{abstract}
The user requires the missing ALGEBRA that connects actual GST spatial

algebra of finite-rank ALGEBRAIC idempotent matrices on the genuine GST

explicit finite polynomial matrix equations in actual global sections
on the projective incidence compactification. Each connected component
of each solution scheme has an independently constructed genuine
algebraic vector bundle and canonical rational Chow/Chern source on

algebra for the TRUE canonical algebraic image, without inserting

Grassmannian test proves a formerly missing nondivisor direction
is found by an intrinsic PGL higher-rank source. We identify
the source-generation implication required to make the alpha
solver succeed for every rational Hodge class.
\end{abstract}
