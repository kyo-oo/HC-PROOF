\begin{abstract}
Starting from the genuine GST Jouanolou spatial incidence
geometry, we give an EXPLICIT rational-matrix formula for
the tautological rank-r algebraic projector in EVERY
Grassmannian rank and ambient dimension, not merely an
assertion that some algebraic idempotent exists.
We then construct finite polynomial Fitting equations
whose actual scheme-theoretic degeneracy loci have
the required original-world algebraic Chern classes.
The construction is functorial for algebraic classifying
maps from arbitrary original smooth projective X.
We derive the original-X Chern-character formula
for arbitrary algebraic bundles using ample twisting,
globally generated quotient classifying maps and finite
Pl\"ucker projectors; no artificial Hodge-to-Chow map
is inserted. An explicit nondivisor test gives a
TRUE closed codimension-two algebraic subvariety of
Gr(2,5) and its exact rational Hodge source.
This extends the existing alpha-indexed polynomial
projector source algebra by replacing abstract
projective-module witnesses with actual matrices
and finite determinantal ideals.
We distinguish existence of a genuine ALGEBRAIC
classifying map from the universal prescribed Hodge
input, where that existence has not been proved.
\end{abstract}
