# Mathbox Gate 3: matched-boundary native primitive-cycle construction

- **Date:** 2026-10-17.
- **Parent:** [all-X primitive hyperplane-relative geometry](2026-10-17-primitive-middle-hyperplane-relative-gate.md).
- **Original exact target:** For all smooth projective complex X, p, rational (p,p) Hodge alpha, build a genuine rational codimension-p algebraic cycle on the original X with canonical Betti class alpha.
- **Mathematical attempt:** Once primitive alpha has been located in the relative Betti image of a smooth hyperplane Y, build **actual signed rational algebraic cycles on X** from geometric subvarieties whose restrictions to Y cancel.
- **Hypotheses:** X any smooth projective complex variety of even dimension 2p, Y any genuine smooth hyperplane section i:Y->X, p>=1; two independently constructed rational codimension-p native cycles Z0,Z1 on the ORIGINAL X; equality of their *actual canonical Betti hyperplane restrictions* i*cl_X(Z0)=i*cl_X(Z1). The equality can be tested by ordinary restriction/cup/Gysin geometry; it never assumes alpha has a target preimage.
- **Constructive theorem:** Set Z=Z0-Z1∈CH^p(X)_Q. Its canonical class satisfies
  \[
   i^*\operatorname{cl}_X(Z)=i^*\operatorname{cl}_X(Z_0)-i^*\operatorname{cl}_X(Z_1)=0.
  \]
  By the universal middle primitive ⇔ hyperplane restriction zero theorem, \(h\smile\operatorname{cl}_X(Z)=0\). If \(\operatorname{cl}_X(Z_0)\neq\operatorname{cl}_X(Z_1)\), the primitive class is nonzero. **This constructs actual primitive native algebraic cycles, rather than only relative rational Betti lifts.**
- **Uniform scope:** No Fermat, K3, product geometry, fixed degree or selected Hodge target is assumed. The theorem is valid for any original X in the even middle range with genuine maps satisfying weak Lefschetz and Gysin self-intersection.
- **Concrete exact test on a cubic fourfold:** Let X be a smooth cubic fourfold containing a plane P, let H=h² and Y a smooth hyperplane cubic threefold. Then cl(3P)|Y=3·(1/3)h_Y²=h_Y²=cl(H)|Y. Their Betti classes on X differ because the primitive Gram \(Z=3[P]-H\) has Z²=24. Thus this exact native boundary-matched algorithm constructs a genuine nonzero primitive algebraic cycle on the original X.
- **Exact Wolfram computation:** Integral intersection Gram in basis (H,P) is [[3,1],[1,3]], projective degree ∫_X h⁴=3, ∫_X h²P=1. Therefore i*P=(1/3)h_Y², i*H=h_Y², and i*(3P-H)=0, while (3P-H)²=24. This tests the *same* cancellation condition the Lean constructor uses.

All use actual native \`codimensionCycles X.X p\` and the existing geometric middle hyperplane cup/restriction interface, and prove exact target primitiveness from two Betti boundary measurements. CI [#39040768572](https://github.com/kyo-oo/HC-PROOF/actions/runs/39040768572) checks these additions in the existing 247-module Hodge integration gate.
- **Audited exact boundary:** This construction requires an independently supplied pair of genuine algebraic cycles with matching restrictions; it gives no constructor of such a pair from an arbitrary rational primitive target α, and no universal spanning theorem. The new open mathematical implication is to construct enough matched-boundary pairs on each arbitrary original X whose canonical primitive Betti classes span the entire rational primitive (p,p) Hodge sector, without assuming those sources or a determinant of full rank.
- **Route success criterion:** Explicit original-X signed cycle Z, canonical primitiveness and nontriviality under directly testable geometric conditions. **Succeeded mathematically.** Kernel CI result must be read at the exact commit before labeling formal verification green.
- **Next discriminating test:** For a proposed genuinely all-X geometric family of codimension-p source subvarieties, calculate its hyperplane boundary map and demonstrate a new relative primitive class *not already preselected as a cycle class*. Producing more special variety incidence matrices alone does not resolve the universal source-birth obligation.
- **Strongest surviving statement:** Boundary cancellation gives a uniform **native** primitive-cycle constructor in every even dimension; it extracts new algebraic directions whenever X already carries geometrically distinct cycles with equal Betti boundary. The universal rational Hodge target remains unchanged.
