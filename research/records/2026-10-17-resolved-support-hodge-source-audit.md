# Mathbox: resolved-support Hodge cycles on every original variety — exact source boundary

- **Date:** 2026-10-17
- **Kind:** direct all-X geometric construction, proof audit, and exact calculation
- **Original target:** For every smooth projective complex variety X, every p, every rational (p,p) class alpha, construct a genuine rational algebraic cycle Z on original X with canonical cl_X(Z)=alpha. The goal's quantifiers remain unchanged.
- **Active obligation:** Gate 3, source-producing geometry for arbitrary primitive classes.
- **What was proved:** For any c≥0, any original smooth projective complex X, any genuine resolved codimension-c algebraic support map f:Y→X and Gysin \(f_*:H^2(Y,Q)\to H^{2c+2}(X,Q)\), any rational Hodge \((c+1,c+1)\) class α **already known to lie in the Gysin image** admits a native rational algebraic cycle on X.
- **Construction:** A Gysin map from a smooth projective resolution Y shifts Hodge bidegree by (c,c). Strictness and semisimplicity of the category of polarizable pure rational Hodge structures supply a rational Hodge (1,1) class β on Y with f_*β=α. Lefschetz (1,1) gives a genuine algebraic divisor D on Y with cl_Y(D)=β. Return \(Z=f_*D\in CH^{c+1}(X)_Q\). Canonical Gysin/Chow naturality gives cl_X(Z)=f_*cl_Y(D)=α. This handles signed rational cycles as well as effective supports.
- **Formal Lean contract:** \`GSTUniversalResolvedSupportHodge.lean\` defines \`ResolvedSupportGysin\` carrying an actual scheme morphism and the independently geometric pushforward, rational Hodge lift and Betti/Chow comparison interfaces. \`nativeCycle_correct\`, \`resolved_support_hodge_class_is_algebraic\`, and \`divisor_supported_hodge_two_is_algebraic\` construct and verify the native target cycle. The source-map properness, resolution existence, analytic fundamental classes and rational Hodge strictness have their stated independent mathematical proofs but are not automatically instantiated by a generic Lean \`ResolvedSupportGysin\` value.

- **Geometry first worked case:** For an arbitrary smooth projective complex fourfold X, p=2, c=1. A rational Hodge (2,2) class in the genuine Gysin image of a smooth resolution of an algebraic divisor on X is represented by pushing an algebraic divisor on that threefold to X.
- **Cheapest exact Wolfram test:** A rational Gysin-image matrix \(F=\bigl(\begin{smallmatrix}1&0\\0&1\\0&0\end{smallmatrix}\bigr)\), target rational Hodge dimension 3, source divisor-Hodge dimension 2. Class (3,−2,0) has a rational source (3,−2); class (0,0,1) is outside the Gysin image, since adjoining it raises the matrix rank 2→3. This demonstrates exactly what the formal theorem constructs and what support does not by itself provide. **These matrices are an abstract test, not a claimed nonalgebraic class on any actual X.**
- **Critical reverse implication (audit):** Every already algebraic codimension-p cycle on X has such a resolved codimension-(p−1) support after choosing projective subvarieties containing its finitely many irreducible components and resolving those supports. On a resolution, the strict transforms of the original codimension-p subvarieties are divisors. Taking a disjoint union handles finite sums. Thus the union of all rational Gysin Hodge-support images of this special degree-two kind equals the algebraic cycle-class image. **Postulating that every rational Hodge class enjoys such resolved support is equivalent to the original Hodge statement** (with the usual projective support-resolution theorems); it is not independent source birth.
- **Additional universal source-channel stress test:** On a cubic fourfold containing a plane, Picard rank is one, so products of divisors yield only the h² line and have zero primitive output. Yet \(Z=3[P]-h²\) is a genuine algebraic primitive class with self-pairing 24. Exact Wolfram matrix test: G=[[3,1],[1,3]], \(\langle h²,Z\rangle=0\), \(\langle Z,Z\rangle=24\). Therefore any Gate-3 proposal using only divisors and their products misses an already algebraic primitive direction on a smooth original X. On P²×P² the divisor-product primitive kernel is nonzero (generator A²−AB+B²), showing this source can be useful on some X but is not uniform.
- **Verdict:** **Proved for the stated supported-class domain** with standard classical geometric comparison inputs; formal Lean reduction green. **No unconditional extension to arbitrary primitive target α**. The first missing implication remains the geometric creation of a resolved support or independent codimension-p algebraic source for such an arbitrary α.
- **Route decision:** Keep the verified theorem as the exact coniveau-(p−1) source handler. Stop trying to finish all-X Hodge by adding a blanket support-coverage hypothesis or by iterating hyperplane/divisor intersections. Both would quietly replace Gate 3 with its own conclusion.
- **Next operation:** Search for an actual codimension-≥2 X-intrinsic incidence, deformation or analytic-to-algebraic mechanism that produces a primitive native class **not already in the supported/algebraic image** as a priori assumed source, and prove its canonical class without a disguised Hodge-preimage condition. Audit each proposed construction on Picard-rank-one primitive cubic fourfolds before generalizing.
- **Success/failure criterion for this route:** A claimed universal source mechanism succeeds only if it constructs a genuine codimension-p subvariety-derived cycle for arbitrary X and alpha from independently defined geometry. It fails as universal progress if the first new step assumes that alpha already has a divisor support, a cycle preimage, or an all-Hodge spanning matrix.
- **Strongest surviving statement:** Every rational Hodge class supported by a resolved codimension-(p−1) algebraic source is represented by a concrete native pushforward divisor on the ORIGINAL X, uniformly in p; verified in Lean. This gives a robust subroutine after support is constructed, while Gate 3 still demands a new support-birth mechanism.
