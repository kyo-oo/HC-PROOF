## Immutable target

The formal target is `GSTClassicalHodgeExactClayStatement.EveryHodgeClassIsRationalAlgebraic`, subject to canonical-semantics verification. Do not replace it with a special-family theorem, an abstract Hodge-to-Chow selector, a nonzero Gram matrix, or a more convenient hypothesis.

## Stop the endless "next step" loop

1. **No proposal-only research turns.** Every substantial research turn must EXECUTE a specific mathematical source-existence attempt (derive a candidate actual scheme/sheaf/perfect complex, compute its exact class/period, prove a new implication, or find a mathematically decisive failure). A high-level plan, reductions repeated from existing records, and lists of additional steps do NOT count as work.
2. **Never promote a compiler to a source.** In `GSTActualXHodgeResidualProjection.lean`, `nativeEulerFullRank_iff_all_targets` proves that the existence of a full-rank matrix built from genuine original-X algebraic cycle columns is **equivalent** to universal representability in that Hodge fiber (for the Stage-2G map). Calling that matrix the “one remaining easy geometry lemma” restates the target. Gram inversion, Euler positivity, Newton/Segre normalization, topological KU duality, diagonal trace and native return do not, alone, supply those columns.
3. **Use the strongest existing negative checks before another route.** The latest `2026-10-21-gst-universal-source-existence-attempt.md` gives an invariant unital polarized algebra countermodel to forcing one-sided native outputs from equivariant diagonal contractions. The full native-image annihilator and native-operator quotient laws also rule out "expansion of the full source image" by merely applying native endomorphisms. These statements do not refute the Hodge conjecture; they bar REPEATING a known insufficient proof mechanism under new terminology.
4. **Demand genuine new geometry.** For any claimed universal source-birth theorem, identify (a) a specific algebraic scheme/Chow/K0 source constructed on an arbitrary original X or a rigorously descended alteration, (b) its canonical Betti class, (c) a proof of nonzero coupling to the prescribed residual that does NOT require alpha to be algebraic, and (d) how this mechanism differs from previously failed same-image/diagonal-only routes. Test arbitrary-X claims adversarially; special curves, CM and K3 products are tests, not proof by extrapolation.
5. **When a mechanism fails, CLOSE THAT MECHANISM.** Record a concrete no-go argument or counterexample and stop regenerating equivalent “next steps” from it. Try an actually different source constructor if feasible. Do not substitute new ontology labels for a missing algebraic output. Never conclude that all future geometric constructions are impossible from a failure of one method.
6. **Communication is evidence, not promises.** Report WHAT was proved/refuted and the exact scope, source paths and SHA, actual GitHub Actions run outcome, plus no more than one short sentence naming any remaining obligation. No “next round we will finally…” or repeated restatements of Gate 3. If a proposed proof fails, say why precisely rather than pretending a new theorem was achieved.
7. **Preserve all project integrity.** Inspect current HEAD; use this branch; keep Lean edits surgical; do not install Lean locally; invoke GitHub Actions to compile each changed Lean module; repair current-revision failures; check `#print axioms` and forbid `sorry`, `admit`, fake inconsistent axioms, or definitions that manufacture surjectivity. Check the original-X universal quantifiers, actual cycle type, canonical comparison, algebraic construction, and Lean kernel proof. If any one fails, classify the result as a verified *restricted/conditional* lemma, not the Hodge solution.
