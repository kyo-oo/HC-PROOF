## Route I — completed universal divisor-to-curve class construction

For EVERY smooth projective X of dimension d>=2 and EVERY rational
Hodge (d-1,d-1) class alpha in H^(2d-2)(X,Q), classical Hard
Lefschetz supplies a rational (1,1) class beta with
  h^(d-2) cup beta = alpha.
The Lefschetz (1,1) theorem constructs an actual rational
algebraic divisor D with cl(D)=beta. Therefore the ACTUAL
codimension-(d-1) algebraic cycle
  Z = H^(d-2) intersect D
represents alpha.

This is a mathematically unconditional standard result for arbitrary
smooth projective X, using independently known classical theorems,
not a newly discovered general Hodge proof.

Combining with codimensions p=0,1,d, the rational Hodge

of dimension at most three. This is the boundary of the unresolved
middle-codimension problem.

## Route II — actual middle primitive on the first hard dimension

Take X=P^2_C × P^2_C, a genuine smooth projective fourfold.
Its rational cohomology ring is Q[a,b]/(a^3,b^3), with a,b the
algebraic hyperplane classes from the two factors. Every H^4
class is of (2,2) type. Let h=a+b.
Cup multiplication on coordinates in (a^2,ab,b^2) is:
  h.(x a^2 + y ab + z b^2)
  = (x+y) a^2b + (y+z) ab^2.
The one-dimensional primitive kernel is generated by
  a^2 - ab + b^2.

The genuinely algebraic cycle
  [P^0×P^2] - [P^1×P^1] + [P^2×P^0]
represents that primitive class; every rational primitive
class on THIS X is a rational multiple of it.

New Lean: GSTMiddlePrimitiveProjectiveProduct.lean verifies the
exact rational cohomology-coordinate kernel, explicit nonzero
generator and construction. Its dedicated gate is 38692915421.
That file does NOT formalize the projective-product cohomology
ring's canonical isomorphism with actual Betti cohomology; this
is a standard independent geometric input.

This is a genuine mathematical primitive-cycle construction
for a concrete smooth projective fourfold, not arbitrary X.

On X×E_i, the factor-selective CM automorphism id_X×[i]

(Riemann-Hurwitz). None of these observations refutes
